# Arshitha S — Portfolio

Personal portfolio of **Arshitha S**, final-year Computer Science and Engineering student at RNS Institute of Technology, Bengaluru. Open to AI/ML, backend, frontend and full-stack roles.

**Live site:** https://arshitha-portfolio-seven.vercel.app

## Pages
- **Home** – about me, education and contact
- **Research** – IJECE paper on stopping role drift in AI agents ([read the paper](https://ijece.iaescore.com/index.php/IJECE/article/view/42596))
- **Projects** – RMIC-Guard, PromptGuard and Secure File Viewer, each with its own page
- **Skills** – skills and achievements

## Tech
A single static `index.html` (HTML, CSS and vanilla JavaScript) plus `photo.jpg`. No build step. Deployed on Vercel.

## Run locally
Open `index.html` in a browser, or run `python -m http.server` in this folder and visit http://localhost:8000.
